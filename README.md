## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, Tailwind CSS 4, Framer Motion, AOS (Animate On Scroll), Glassmorphism UI
- **AI & ML**: Google GenAI SDK / Vertex AI Gemini, LangChain, LangGraph, Scikit-Learn, PyTorch, Anomaly Matrix Engine
- **Backend & Data**: Python 3.11, FastAPI, Node.js, Express, MongoDB, Redis, Docker
- **Email & Communication**: EmailJS integration for direct candidate inquiries

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Development Server
```bash
npm run dev
```
Open `http://localhost:5173` to preview locally.

### 3. Production Build
```bash
npm run build
```
Generates production assets in `dist/`.
